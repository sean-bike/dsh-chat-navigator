# 对话导航栏插件 —— 基于“悬停摘要”的双模块设计方案（V2.1）

**设计核心理念**：
- **模块 A（右侧精简导航条）**：悬停圆点 → 弹出摘要面板；分支操作作为摘要面板的**二级交互**存在。
- **模块 B（完整管理面板）**：独立滑出，负责全局树形管理，不受摘要面板干扰。

---

## 1. 模块 A：精简导航条（右侧垂直队列）—— 交互重构

### 1.1 基础交互（保留现有设计）
- **悬停圆点**：在圆点旁边（建议左侧或右侧）弹出**摘要面板**，显示该轮对话的内容预览（前 80 字）、时间戳、角色（用户/助手）徽标。
- **单击圆点**：主对话区跳转至该节点，导航条滚动将该圆点置中。

### 1.2 分支视觉标记（在圆点本体上）
在保留摘要面板的基础上，圆点本身增加极简的**分支状态标记**：

| 节点类型 | 圆点视觉表现 |
| :--- | :--- |
| **无分支节点** | 纯色圆点，无额外标记 |
| **拥有兄弟节点（同级分支）** | 圆点右上角增加一个**微小的空心圆环**（直径 2px） |
| **拥有子节点（下级分叉）** | 圆点右下角增加一条**极短的横线**（—） |
| **同时拥有兄弟和子节点** | 同时显示圆环 + 横线 |

> 这些标记非常细微，**不干扰**现有摘要面板的触发逻辑。

### 1.3 分支交互 —— 完全整合进摘要面板（核心变更）

当用户**悬停**圆点时，摘要面板弹出。此时，摘要面板不再只是一个信息卡片，而是承担起**分支操作入口**的角色。

**摘要面板的新布局**（从上到下）：

```
┌─────────────────────────────┐
│ 👤 用户  |  10:32           │ ← 头部信息
│─────────────────────────────│
│ “请帮我设计一个登录页面...” │ ← 内容预览（原有）
│─────────────────────────────│
│ 📌 当前路径                 │ ← 分支信息区（新增）
│  父级: ○ 需求讨论           │
│  同级: ○ 方案A  ○ 方案B    │ ← 可点击跳转至兄弟节点
│  子级: ○ 细化需求           │ ← 可点击跳转至子节点
│─────────────────────────────│
│ [➕ 在此分叉]  [🌳 全览]   │ ← 操作按钮（新增）
└─────────────────────────────┘
```

**各新增区域交互说明**：

- **同级 / 子级圆点列表**：
  - 显示当前节点的**直接兄弟节点**（最多 3 个）和**直接子节点**（最多 3 个），以微型圆点 + 简短标签（如“方案A”）展示。
  - **悬停**这些微型圆点 → 摘要面板**动态切换**为该节点的摘要信息（即面板内容刷新）。
  - **单击**这些微型圆点 → 主对话区跳转，导航条滑动，摘要面板关闭。

- **“在此分叉”按钮**：
  - 点击后，直接在当前节点下创建一个新的子分支，输入框自动聚焦。摘要面板关闭。

- **“全览”按钮**：
  - 点击后，**打开模块 B（完整管理面板）**，并高亮当前节点。这是从精简模式跳转到复杂模式的桥梁。

---

## 2. 模块 B：完整管理面板（独立滑出）—— 保持不变

该面板独立于摘要交互，专门处理重型管理任务，不受悬停影响。

| 功能区域 | 内容 |
| :--- | :--- |
| **顶部工具栏** | 搜索框、视图切换（缩进列表 / 缩略拓扑图）、批量选择模式 |
| **主体树形列表** | 缩进 + 连线 + 内容预览 + 时间戳，支持拖拽重组、折叠/展开子树 |
| **底部操作栏** | 总节点数、删除选中、导出分支、合并分支 |

**与模块 A 的联动**：
- 在模块 A 的摘要面板中点击 **“🌳 全览”** → 模块 B 从右侧滑出。
- 在模块 B 中点击任意节点 → 主对话区跳转，导航条同步滚动，模块 A 的摘要面板（若打开）自动刷新内容。

---

## 3. 完整交互流程演示（基于摘要面板）

假设你正在一条主路径上，想查看并切换到某个旁支：

1. **发现分支**：右侧导航条上，当前节点圆点右上角有一个**空心圆环**（提示有兄弟节点）。
2. **悬停查看**：鼠标悬停该圆点，**摘要面板**弹出，显示对话内容预览。
3. **查看分支详情**：在摘要面板的“分支信息区”，看到同级列表中有 `方案A`、`方案B` 两个微型圆点。
4. **预览旁支内容**：鼠标悬停 `方案B` 微型圆点，摘要面板**动态刷新**，显示 `方案B` 的对话预览（无需离开当前节点）。
5. **切换过去**：点击 `方案B` 微型圆点，主对话区跳转至 `方案B`，导航条滑动将 `方案B` 置中，摘要面板自动关闭。
6. **创建新分支**：想从 `方案B` 再衍生一个新想法，再次悬停 `方案B` 的圆点，在摘要面板中点击 **“➕ 在此分叉”**，输入框聚焦，直接开聊。
